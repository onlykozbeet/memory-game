## Локальный запуск

Требуется Node.js версии `20.19+` или `22.12+` и npm.

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

3. Откройте адрес, указанный Vite в терминале (обычно `http://localhost:5173`).

## Дополнительные команды

```bash
npm run build    # собрать production-версию в dist/
npm run preview  # локально открыть production-сборку
npm run lint     # проверить JavaScript через ESLint
```

## Структура проекта

- `src/js/utils/dom.js` — функция `createElement` для создания DOM-элементов.
- `src/js/game/` — создание колоды и логика игры.
- `src/js/ui/` — создание и обновление игрового интерфейса и модальных окон.
- `src/js/storage/` — сохранение и загрузка результатов таблицы лидеров.
- `src/styles/` — стили приложения на SCSS.
